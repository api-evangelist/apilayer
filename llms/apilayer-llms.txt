# APILayer

> APILayer is a unified API marketplace: one account, one API key, and one dashboard unlock production-ready REST APIs for geolocation, finance, news, aviation, scraping, and data validation. Trusted by 2.2M+ developers handling 30M+ API calls per month. Every API is manually reviewed for quality, reliability, and performance, and free plans are available on every API. APILayer is an Idera, Inc. brand.

The APILayer suite includes IPstack (IP geolocation), Positionstack (forward/reverse geocoding), Scrapestack (proxy and web scraping), Marketstack (stock market data), Mediastack (news data), Aviationstack (flight data), Mailboxlayer (email validation), Countrylayer (country data), and Serpstack (Google search results data). Each API has its own pricing plans; signup is free with no credit card required at https://app.apilayer.com/signup.

## Geolocation APIs
- [IPstack](https://apilayer.com/products/ipstack): Locate and identify website visitors by IP address — 2M+ locations, IPv4/IPv6, VPN/proxy detection
- [IPstack Documentation](https://docs.apilayer.com/apilayer/docs/ipstack): IPstack API reference and integration guides
- [Positionstack](https://apilayer.com/products/positionstack): Accurate forward and reverse batch geocoding REST API covering 2B+ addresses and places
- [Positionstack Documentation](https://docs.apilayer.com/apilayer/docs/positionstack): Forward/reverse geocoding endpoints, authentication, and errors
- [Aviationstack](https://apilayer.com/products/aviationstack): Free, real-time flight status and global aviation data API — flights, airlines, airports, routes
- [Aviationstack Documentation](https://docs.apilayer.com/apilayer/docs/aviationstack): Flight tracking endpoints and parameters

## Scraping APIs
- [Scrapestack](https://apilayer.com/products/scrapestack): Real-time, scalable proxy and web scraping REST API — 35M+ IPs, JavaScript rendering, CAPTCHA handling
- [Scrapestack Documentation](https://docs.apilayer.com/apilayer/docs/scrapestack): Scraping endpoints, JavaScript rendering, POST requests, and premium proxies
- [Serpstack](https://apilayer.com/products/serpstack): Real-time, accurate Google search results (SERP) API
- [Serpstack Documentation](https://docs.apilayer.com/apilayer/docs/serpstack): SERP endpoints, search parameters, and result objects
